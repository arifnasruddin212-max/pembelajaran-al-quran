# 📖 Pembelajaran Al-Qur'an

Repository pengembangan media, bahan ajar, game edukasi, dan sumber belajar digital untuk Pembelajaran Al-Qur'an.

## 🎯 Tujuan

Repository ini dikembangkan sebagai pusat dokumentasi dan pengembangan pembelajaran Al-Qur'an yang interaktif, kontekstual, dan relevan dengan kebutuhan mahasiswa serta pendidik.

## 📂 Struktur

- `games/` — game edukasi interaktif
- `materi/` — bahan ajar Al-Qur'an, Ulumul Qur'an, Tafsir, dan Tajwid
- `media/` — media presentasi, infografis, dan media interaktif
- `referensi/` — artikel, buku, dan jurnal rujukan
- `dokumentasi/` — dokumentasi pengembangan dan implementasi

## 🎮 Game

### Qur'anic Word Match
Game penguatan pemahaman makna kosakata Al-Qur'an kata-per-kata untuk mahasiswa PAI.

Materi awal mencakup Al-Fatihah, An-Nas, Al-Falaq, Al-Ikhlas, dan Al-Lahab.

> Repository ini akan terus dikembangkan secara bertahap sesuai kebutuhan pembelajaran.
